WIP: My Life as an Interdimensional Warrior

Runtime Sprite Generation

The game takes place across infinite worlds generated by the LLM. When the player visits a world, the LLM generates a cast of characters, including a visual description. The visual description is given to the image generation model to create keyframe sprites for each character.

Natural Dialogue in Combat

Depending on their personality, NPCs react to all sorts of events in combat, and can engage the player in taunts or serious diplomacy.

Turn-based Combat

The game uses a simple JRPG combat system to keep a measured pace so the characters can have detailed dialogues, and so fewer animation frames are needed.
